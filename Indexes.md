# Индексы

## 1. Определение индексов и их типов, необходимых для эффективного исполнения запросов

Дополнительные индексы для PostgreSQL 18.6. Индексы, создаваемые для `PRIMARY KEY` и `UNIQUE`, сохраняются и не дублируются.

| № | Таблица | Атрибуты | Тип | Описание |
| --- | --- | --- | --- | --- |
| 1 | `spool` | `area_id`, `isometric_revision_id` | B-tree, составной | Поиск спулов объекта и их ревизий. Используется в выборках спулов по объекту и расчёте тоннажа. |
| 2 | `component` | `spool_id` | Hash | Получение компонентов выбранного спула по точному совпадению `spool_id`. |
| 3 | `isometric_revision` | `issue_date` | B-tree | Поиск ревизий, выпущенных после указанной даты, в запросе 1.1. |
| 4 | `welder_certificate` | `welder_id` | Hash | Проверка наличия сертификатов у сварщика, определение стажёров в запросе 1.3 и представлении `welder_category`. |
| 5 | `inspection` | `weld_joint_id` | Hash | Получение проверок соединений, найденных по составу пакета испытаний: спулы -> компоненты -> сварные соединения -> проверки. |
| 6 | `equipment` | `area_id` | Hash | Получение оборудования выбранного объекта в запросах 1.5 и 1.7. |
| 7 | `delivery` | `delivery_date` | B-tree | Получение поставок за указанный период в запросе 1.6. |
